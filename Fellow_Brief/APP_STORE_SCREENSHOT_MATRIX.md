# LensBeacon App Store Screenshot Production Matrix

Apple currently permits 1–10 screenshots per platform, in PNG/JPEG/JPG, with no alpha/transparency.

## iPhone — primary set
Use the largest current accepted 6.9-inch portrait canvas for the primary set:
- 1320 x 2868 px (current 6.9-inch group)
Apple will scale accepted screenshots for smaller displays when separate sizes are not supplied.

Recommended 10-story sequence:
1. Spot camera glasses. On your terms.
2. See what's nearby — live Dashboard
3. Understand why — evidence per flag
4. Confidence without guesswork — Possible / Likely / Strong
5. Simple proximity — Near / Nearby / Far
6. Keep a private sightings history
7. Mark your own devices — Mine
8. Background monitoring + timely alerts
9. Live Activity + Home Screen widget
10. $9.99 once — Lifetime Unlock, no subscription

## iPad — primary set
Use current 13-inch portrait canvas:
- 2064 x 2752 px
Landscape alternative: 2752 x 2064 px
Recommended approach: capture the real iPad three-column experience, not a stretched iPhone.

## Apple Watch
App Store Connect accepts one of these screenshot sizes:
- Ultra 3: 422 x 514
- Ultra 2 / Ultra: 410 x 502
- Series 11 / 10 / 12: 416 x 496
- Series 9 / 8 / 7: 396 x 484
- Series 6 / 5 / 4 / SE 3 / SE 2 / SE: 368 x 448
- Series 3 / 2 / 1: 312 x 390

IMPORTANT: Apple requires the same Watch screenshot size consistently across all localizations.
For the strongest current submission, use the Ultra 3 422 x 514 set if the app's App Store Connect
configuration and target device support make that appropriate.

Recommended Watch screenshot sequence, up to 10:
1. Camera glasses nearby
2. Likely detection
3. Possible detection
4. Strong detection
5. Signal/proximity view
6. View details / evidence
7. Scanning state
8. Notification / timely alert
9. Live Activity / Smart Stack treatment
10. Clean empty state / ready to scan

## Capture rule
Do not fabricate screenshots. Generate these from the actual Xcode Simulator/device build.
The screenshot copy and framing should remain calm and factual.
